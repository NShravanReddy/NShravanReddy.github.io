Usage: {% include post-list.html posts=site.posts limit=5 %} {% include post-list.html posts=year.items %} Optional `limit` truncates the list (used for the homepage "Recent posts"). Renders each post's date, title (external_url aware, with ↗ marker), and a short excerpt. {%- endcomment -%} {%- assign _posts = include.posts | default: site.posts -%} {%- if include.limit -%} {%- assign _posts = _posts | limit: include.limit -%} {%- endif -%}

    {{ post.description | default: post.excerpt | strip_html | truncatewords: 25 }}
